## 👋 About

Full-stack engineer focused on **SaaS products, backend architecture and complex system integrations**. I work across the whole stack, from REST and real-time APIs to event-driven services and performant interfaces, with a consistent bias toward **scalability, security and clean architecture**.

- 🧠 **AI in production:** LLM integrations, RAG pipelines, MCP, cost/quality optimization
- 🏗️ **Distributed backends:** microservices, event-driven design, message queues
- 💳 **Real-world systems:** payments, webhooks, omnichannel (WhatsApp) platforms
- 📊 **Engineering that holds up:** observability, tracing and monitoring, not just shipping
- 🤖 **AI-assisted development:** shipping faster with agents, harnesses and custom tooling

> Open to challenging work on scalable architectures, AI integrations and complex product engineering.
